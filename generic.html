Occupational hearing loss analysis with SQL

Occupational Hearing Loss Analysis in the Mining Industry is an end-to-end data pipeline built in Google BigQuery. Its main goal is to track how miners' hearing degrades over time by combining medical test records, workplace noise levels, and lifestyle factors like smoking. To keep the analysis highly accurate, the project uses a "Worst Ear" approach. Instead of averaging the results of both ears—which can easily hide severe damage in just one ear—the script automatically finds and isolates the highest decibel loss (worst_ear_loss_dB) for every single test session. On the technical side, the pipeline leverages Advanced SQL concepts to deliver fast, high-performance trend analysis without using slow and heavy self-joins. Instead, it uses layered CTEs to organize the data and Window Functions (LAG) to calculate year-over-year changes (dB_worsening_delta). With this solution, occupational health departments can finally move from reactive care to proactive prevention. It helps companies catch at-risk workers early and allows safety managers to make data-driven decisions about protective gear (PPE) and work shifts. Best of all, the entire relational dataset is fully simulated using a smart, memory-layered WITH ... UNION ALL architecture. This means the project is ready for instant, one-click execution in BigQuery’s free sandbox tier!
